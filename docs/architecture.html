核心组件

三大引擎，驱动拟人体验

对话大脑、声音引擎、听写引擎协同运转，串行调度保障稳定，数据安全贯穿始终。

LLM

对话大脑

llama.cpp 便携版加载 Qwen3-4B 量化模型，在 GPU（CUDA）上运行 OpenAI 兼容服务。支持切换至云端 MiMo API，回复自动标注朗读风格。

TTS

声音引擎

Qwen3-TTS 经 NVIDIA GPU（CUDA）合成（云端 MiMo 备选），每个角色有专属参考音色，朗读风格随回复自动变化。

ASR

听写引擎

Qwen3-ASR 本地离线识别，录音转文字全程不上传。

Lock

串行调度

全局锁串行化 TTS/ASR 调用，避免共享服务冲突。

Roles

内置角色

小拟、大帅、东北老铁、四川妹儿，一键切换。每个角色独立人设 + 专属音色。

数据安全

模型、声纹、对话记录默认全部留在本机 data 目录。不依赖云端，断网亦可对话与朗读。

数据不出本机
数据流向

一句话的旅程

从你开口说话到小拟用语音回应，数据在三层引擎间流转，全程不离开本机。

01

用户输入

文字或语音输入，ASR 离线转写为文本，送入后端等待推理。

02

模型推理

文本送入 LLM，结合角色人设生成回复，并自动标注朗读风格（[style:xxx]），经 FastAPI 返回前端。

03

声音合成

回复文本按标注的风格经 TTS 合成，用当前角色的专属音色朗读，音频流返回前端播放。
