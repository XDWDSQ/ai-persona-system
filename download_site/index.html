手机上怎么用
1
手机浏览器打开 ngrok 隧道地址（电脑上运行 ngrok http 8000 后获得），输入访问口令登录
2
在浏览器菜单选择 「添加到主屏幕 / 安装应用」
3
主屏幕上打开即 独立窗口运行，无地址栏，和原生 App 一样

网页端已支持离线秒开与安装到桌面（PWA）。安卓 APK 已停止开发，后续统一使用网页版。

注意：以上均为脱敏版，不含云端 API 密钥（.env 与 config.json 中的 api_key）。 云上密钥通过 .env 文件提供（回退机制自动生效）。 更新包解压到项目根目录选「替换现有文件」，保留 data/ 不动，然后重启服务。
